# 临摹对比诊断（sketchfix）

给定一张**样张**和一张**临摹**，输出一份"哪里画错了、错多少、怎么改、怎么复查"的报告。
纯本地运行，纯几何算法（OpenCV + numpy），**不联网、不用 AI 大模型**。
除了这句话，本项目的所有内容全部由 AI 生成。

## 能做什么

按三层顺序诊断，先大后小：

| 层 | 看什么 | 典型结论 |
| --- | --- | --- |
| 比例/构图 | 整体长宽比、外轮廓边界、重心位置、主轴角度 | 「长宽比 0.38，样张 0.44（0.88×，窄 12%）」 |
| 线稿/轮廓 | 逐格比对骨架线的缺失、多余、整体偏移、墨量 | 「下中右区缺线：平均偏离 31.8px（阈值 11px）」 |
| 明暗关系 | 逐格比对低频明暗与对比度 | 「下右区偏暗：平均暗 13 级，最深 21 级」 |

每条结论都带六项：**现象 / 量化 / 位置 / 改法 / 复查 / 置信度**，
并按"根因优先"排序——整体比例不对时，会先把比例结论放前面，并暂时压掉逐区的
线稿偏移结论，避免"越改越乱"。

## 安装

```powershell
python -m pip install opencv-python numpy
```

Python 3.9+ 即可。中文路径已处理（用 `np.fromfile` + `cv2.imdecode` 读图）。

## 用法

```powershell
python -m sketchfix --ref 样张.png --copy 临摹.jpg --out out
```

输出到 `--out` 目录：

- `report.md` —— 报告正文（先结论，后清单，最后图）
- `overlay.png` —— 在临摹上框出问题区（编号对应清单）
- `heatmap.png` —— 差异热图
- `aligned_copy.png` —— 配准后的临摹（用于核对对齐是否可信）
- `findings.json` —— 结构化结果，便于二次处理

### 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--ref` | 必填 | 样张路径 |
| `--copy` | 必填 | 临摹路径 |
| `--out` | `out` | 输出目录 |
| `--align` | `similarity` | `similarity`=旋转+等比缩放+平移；`homography`=允许透视 |
| `--manual-quad` | 无 | 手工指定临摹纸的四个角，格式 `x1,y1,x2,y2,x3,y3,x4,y4`（顺时针，从左上开始） |
| `--strictness` | `1.0` | 严格度，调大只报更严重的问题 |
| `--top` | `5` | 最多列几条 |

**`--align` 怎么选**：默认的 `similarity` 只允许旋转/等比缩放/平移，所以"把人物画窄了"
会留在残差里，被比例层如实报出来。只有当**纸张本身拍歪了**（手机斜拍、纸张卷曲）时，
才用 `--align homography`；此时透视会被对齐吸收掉，比例类结论只能当参考——
报告开头会有相应提醒。

## 三件必须知道的事（能力边界）

1. **只比几何，不懂内容**。它不知道哪条是手指、哪条是衣褶，只知道"样张这里有线、
   临摹这里没有"。所以"该不该加这条线"仍需你自己判断。
2. **配准是前提**。两张图必须拍的是同一个姿势、同一个朝向。配准失败时报告会写
   「无法可靠比对」，此时除整体比例/空白外的结论都不可信——请重拍正面、四角对齐。
3. **明暗只给相对量**。用的是低频明暗的格均值与峰值差值（0~255 级），不是绝对
   灰度；受拍摄光照影响，跨设备的"级"不能直接横比。

## 自检

```powershell
python tests\run_checks.py          # 五项端到端验收 A~E
python -m sketchfix.layers.line     # 线稿层单测
python -m sketchfix.layers.value    # 明暗层单测
python -m sketchfix.layers.proportion
```

`tests\run_checks.py` 覆盖：
A 平移 6px + 旋转 2°（残差 < 1.5px）、B 横向压到 0.86（比例错误可检出）、
C 抹掉一条腿 + 多画一条横线（缺线/多线可检出）、D 右下压暗 34 级（偏暗可检出且
未改动区不误报）、E 每条结论六项齐全 + 配准失败时诚实降级。
